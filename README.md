## ⚡ Features

- **🔐 Secure Authentication**: Simulated Login/Registration flow with validation.
- **👤 Profile Management**: Users can view and update their profile details.
- **💾 Persistent Data**: Uses `localStorage` to keep users logged in and save data (mocks a real backend).
- **📱 Responsive Design**: Built with Bootstrap 5, ensuring it looks great on mobile and desktop.
- **🛡️ Route Protection**: Prevents unauthorized access to the Profile page.

---

## 🛠️ Tech Stack

- **Frontend Framework:** [React.js](https://reactjs.org/) (Vite)
- **Styling:** [Bootstrap 5](https://getbootstrap.com/)
- **Routing:** [React Router Dom v6](https://reactrouter.com/)
- **State Management:** Context API (Custom `AuthContext`)
